# Systems

Part one of the database: one row per **platform**, not per machine. The same
hardware running Debian bare-metal, a Crostini container and ChromeOS Flex is
three rows, because telling those apart is the point of the comparison.

`system_id` is a hash of the identifying host facts (hostname, OS, arch, CPU
model, thread count, memory rounded to GiB, platform). Every run in
[RESULTS.md](RESULTS.md) joins to a row here by that id. It is derived, not
stored, so runs recorded before this table existed still join correctly.

Regenerated by `./bench sysdb`. **Do not edit by hand.**
